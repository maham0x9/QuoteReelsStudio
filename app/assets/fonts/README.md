# Bundled fonts

Drop any `.ttf` / `.otf` files in this folder and the app will pick them up
automatically when rendering text overlays. Bundling at least one font is
recommended so renders look the same on every Windows machine — Inter,
Montserrat, and Bebas Neue are popular choices for vertical quote videos.

If this folder is empty the renderer falls back to system fonts (Arial /
Segoe UI on Windows, DejaVu Sans elsewhere).
